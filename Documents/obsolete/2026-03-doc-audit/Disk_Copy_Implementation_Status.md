# ディスクコピー機能実装状況

最終更新: 2025/06/06

## 実装完了した機能

### ファイル単位コピー（基本機能）
- [x] 異なるイメージ間でファイルをコピー
- [x] 同一ファイルシステム間のコピー（Hu-BASIC → Hu-BASIC）
- [x] 異なるディスクタイプ間のコピー（2D → 2DD）
- [x] テキスト・バイナリファイル両対応
- [x] 上書き防止（既存ファイルがある場合はエラー）
- [x] CLIコマンド: `copy <source> <dest> <filename> --source-fs <type> --dest-fs <type>`

### ファイル単位コピー（追加機能）
- [x] 空き容量チェック - コピー先の空き容量不足時のエラー処理
