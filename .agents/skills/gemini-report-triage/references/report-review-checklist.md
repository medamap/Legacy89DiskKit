# Report Review Checklist

- Does the report identify the instruction or task id?
- Does it summarize the result without hand-waving?
- Does `changed_files` match plausible repo paths?
- Do `commands` match the requested verification?
- Does `evidence` point to concrete files, tests, or outputs?
- Are remaining risks explicit?
- If the task was not fully done, did the report say so clearly?

Reject the report if any required section is missing or unsupported.
